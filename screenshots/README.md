# Screenshots Directory

Place screenshots of your running application in this folder to display them automatically on GitHub.

To make them show up on the main README:
1. Capture screenshots of your running local application (`http://localhost:5173`).
2. Crop them to standard desktop/mobile views.
3. Save them in this directory using the following names:
   * **`home.png`**: The hero landing page view.
   * **`items.png`**: The listings noticeboard view.
   * **`details.png`**: A single item details page view.
   * **`dashboard.png`**: The user dashboard (listings & claims tab).
   * **`add_item.png`**: The report item form page.
   * **`mobile.png`**: A smartphone-sized view of the home page or dashboard.
4. Commit and push the files to your GitHub repository!
